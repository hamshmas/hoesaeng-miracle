# 회생의기적 — Landing Page

블랙스톤 법률사무소가 운영하는 빚탕감 전문 브랜드 "회생의기적"의 랜딩페이지.

## Files
- `index.html` — Single-file landing page (all CSS inline)
- `profile.png` — 대표변호사 이승진 프로필 사진
- `.nojekyll` — GitHub Pages용 Jekyll 비활성화

## Deploy to GitHub Pages
1. GitHub에 새 repo 만들기 (예: `hoesaeng-miracle`)
2. 이 폴더에서:
   ```bash
   git remote add origin https://github.com/<USERNAME>/hoesaeng-miracle.git
   git push -u origin main
   ```
3. GitHub repo → **Settings → Pages** → Source: `main` / root → Save
4. 1~2분 후 `https://<USERNAME>.github.io/hoesaeng-miracle/` 접속

## Notes
- 자필후기/로톡/유튜브 썸네일은 외부 URL 직접 참조 (본 사이트와 동기화)
- 변호사 프로필만 자체 호스팅
